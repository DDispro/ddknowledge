# 审核规范（Source of Truth 标准）

进入 `knowledge/` 的内容 = **Source of Truth**，意味着：
**别人（或未来的你）可以不加怀疑地引用它。** 因此审核是知识库质量的生命线。

## 硬性标准（不满足则退回，不得入库）

1. **准确**：事实、数字、结论经过核对，无常识性错误。
2. **可追溯**：`source` 字段必须填写真实出处（原文链接/本地文件名/口述来源）。
3. **无版权风险**：不做大段原文搬运，用自己的话总结；引用少量原文需注明出处。
4. **结构合规**：front-matter 完整，正文成文（不是随手粘贴的草稿）。

## 质量要求（建议标准）

- **精炼**：一篇文章一个主题，删掉冗余；能 300 字说清的不写 1000 字。
- **可复用**：结论、方法、清单要能直接指导未来的自己或他人。
- **不重复**：与既有条目主题重复时合并，或在新条目中链接旧条目。
- **分类标签合理**：分类选一个主类，标签 2–5 个、用词统一。

## 审核清单（每周过目时逐项打勾）

```
□ 事实准确
□ 出处可追溯
□ 内容为自主总结（非搬运）
□ 精炼成文
□ 无重复条目
□ 分类、标签合理
□ status: approved
```

## 如何处理"存疑"内容

- 无法核实准确性的 → **不进入 knowledge/**，留在 `source/` 并标注"待核实"。
- 时效性强的内容 → 条目中注明日期，必要时更新旧条目而非新增。
- 观点类内容 → 标注是"观点/经验"而非"事实"，写明适用场景。
