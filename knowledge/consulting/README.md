# consulting —— 品牌营销咨询方法论

本分类沉淀品牌营销咨询的方法论知识，是知识库的核心资产。

## 内容原则

- **只保留方法论知识，不保留案例内容**：原始资料中的案例（公司/品牌的具体营销实践）仅用于理解方法论，不写入知识库。
- **不含咨询机构品牌名**：知识库整合了多家咨询机构的方法论来源，为避免误导，条目中不出现任何咨询机构品牌名或人名，方法模型一律用通用名称（如"品牌战略铁三角""产品围棋模型"）。

## 子分类

| 子目录 | 内容 |
|--------|------|
| `brand/` | 品牌核心理论：品牌定义（承诺+记忆体）、品牌资产、品牌三进程、超级符号、品牌三原理、品牌战略铁三角 |
| `growth/` | 增长方式与营销执行：4P变量、产品/推广/渠道驱动型、价格、包装、命名、超级话语、卖点、定力定型定投、低成本建品牌、跨界营销、产品开发 |
| `strategy/` | 战略与经营：战略定义、选战场、定位、企业本质与三位一体、企业三原理、产品结构与品类、生意生存原理、使命、5力、管理内核、组织、咨询关系、社会责任 |
| `essays/` | 观点文章与方法论观点集：目标消费者、整合营销、品牌是结果、至诚无息、方法论三十八条等 |

## 使用提示

- 所有条目为整理初稿（`status: draft`），经人工审核后改为 `approved`。
- 个别条目因源材料为图片页存在缺口，以"⚠️ 待补充"标注。
- 本分类成熟后，将作为咨询 SKILL（`skill/ddknowledge-consultant`）的核心知识源。
