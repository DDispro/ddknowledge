# dd-place：渠道

## 核心方法论速览（浓缩自知识卡）
1. 渠道驱动型生意：顾客无法抹除信息差（评估难度高 / 可选太多无统一标准），第一反应是"去哪里买、找谁买"。
2. 渠道也是顾客：渠道就是第一波顾客；渠道的意愿与认知充分决定这类生意的增长。
3. 营销核心：把 4P 设计成渠道的"意愿与认知的统一"——让渠道愿意卖、知道怎么卖。
4. 策略 = 划战场 + 构建战场资源：告诉渠道商"这个战场上我拥有最多最强大的武器和优势，跟着我打无往而不利"。
5. 这类生意对差异化概念定义、行业标准与背书、品牌资源实力更加重视。
6. 4P 行动模式：产品端（细分特征/选择标准/背书认证）、渠道端（培养专家/生动化/培训）、推广端（紧贴渠道投放/官方补贴/行业公关）、价格端（统一价/官方高价/赠品替代折扣）。

## 触发场景
- 用户处于高信息差品类（厨电、家居、金融、茶叶茶具、礼品等）。
- 用户需要渠道招商、渠道赋能、经销商管理建议。
- 用户需要渠道价格体系设计。
- 用户需要判断"该不该铺渠道、怎么让渠道愿意卖"。

## 场景SOP
### 场景A：诊断（渠道能力审查）
1. 判定信息差：顾客能否自主抹除信息差（评估难度 / 选择标准是否统一）？
2. 评估渠道状态：渠道是否愿意卖（意愿）？是否知道怎么卖（认知）？
3. 检核资源供给：是否划定了战场、是否提供了标准/背书/资源实力？
4. 输出诊断结论：卡在意愿还是认知，缺哪类战场资源。

### 场景B：咨询（渠道策略问答）
1. 明确信息差类型，确认是否渠道驱动型生意。
2. 推导打法：划战场（选一个渠道商可打的战场）→ 构建资源（标准定义、背书认证、培训话术）→ 统一意愿与认知。
3. 给出 4P 协同建议（产品/价格/推广如何服务渠道）。
4. 指出常见错误：只投前端广告、忽视渠道认知赋能、直接给终端降价。

### 场景C：成果物生成（渠道方案）
1. 输出"战场定义"：渠道商可打的战场 + 我方最强武器与优势清单。
2. 输出渠道赋能体系：培训/话术/生动化/分级管理与优秀经验复制。
3. 输出渠道价格体系：统一价、官方高价为零售留优势价、以赠品替代折扣。
