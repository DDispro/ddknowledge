# dd 方法卡：KV海报（03_surface/poster）
> ⚠️ **本卡由以下条目合成**（知识库无独立KV海报条目）：consulting/brand/品牌三进程-记忆惯性信仰、超级符号-嫁接文化原型；consulting/growth/超级话语-口号与广告语设计、卖点金字塔（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- KV海报（主视觉）是品牌资产在单一画面上的最大化展示面：把记忆体（命名＋符号）与承诺（产品＋话语）装进一张画面，让终端陈列即体验。
- KV设计的根本任务，是让"记忆三原则"（醒目、简单、重复）与"说动"（一句话购买指令）在同一画面统一。
- 一张KV就是一次购买前序体验的浓缩：被看见 → 被记住 → 被说动 → 走向购买。

## 方法要点

### 1. 主视觉＝品牌资产最大化的展示面
- 把品牌资产（符号、话语、命名）作为画面的绝对主角，能放多大放多大。
- KV不是艺术创作，是资产展示：一切画面元素为记忆与识别服务。

### 2. 记忆三原则在KV中的落实
- 醒目：品牌资产能放多大放多大；干扰信息能去掉最好去掉；放置的位置能多中心就多中心。
- 简单：简单才容易被复述；3秒能说完，15秒就能播放5遍；简单能省制作费。
- 重复：在所有地方部署同一套品牌资产；持续投放同一个广告；除非有了新资产，否则不做新广告——KV与包装、终端、广告用同一套资产。

### 3. 视觉母体私有化（超级符号）
- KV主视觉应调用与品类/场景强相关的文化母体，并做私有化改造（嫁接文化原型：人们只认识他们已经认识的东西、只记得他们已经记得的东西）。
- 符号就是资产：KV是符号资产被持续重复积累的触点之一，不与包装终端脱离。

### 4. 一句话购买指令（超级话语）
- KV文案遵循超级话语规则：口语化、陈述句/行动句、说动不说清、包含产品名。
- 一句话如果什么也没定义、也没提行动要求，就不要用；需要解释就扔掉，直接用解释的那句话。

### 5. 信息层级＝卖点金字塔自上而下
- 卖点要精炼＋具体（非形容词）；外立面空间有限，只能呈现最主要的部分。
- 主信息按卖点金字塔由强到弱取舍：领导者实证特权 → 热销实证 → 第三方认可资质背书 → 比竞品更能满足功能 → 技术特征强化说服力 → 降低消费门槛或成本。
- 把所有空间填充同一个主卖点效果才好；次级卖点只做补充说明，不能抢戏。
- 购买认知路径：不确定 → 少损失 → 从众 → 证据证实范围扩大 → 安全感提升 → 满足功能 → 极确定。

### 6. KV＝终端陈列即体验
- 货架的本质是产品体验空间：KV与陈列共同创造良好的体验氛围，自动卖货。
- 在购买环境中的人是信息搜集者：购买理由降低决策成本，引导顾客体验，促使人买得更快、买得更多。
- KV需要完成3大任务：吸引受众注意、激发好奇；创造产品体验、引导决策；提供购买理由、鼓动尝试。

### 7. AI生图Prompt规范（中英双语）
- 画面构成：明确主视觉主体（品牌角色/超级符号/产品）、信息层级布局（主卖点文案位、品牌名位）、背景与留白。
- 色彩：以品牌色为主色，高对比、干净背景；色彩服务于醒目原则。
- 风格关键词：写实/扁平/插画/3D等风格词＋质感词（高质感、商业广告级等）＋画质词（8k、Masterpiece等）。
- 双语：中文Prompt描述画面构成与信息（供内部沟通），英文Prompt用于生图平台（画面主体描述、风格、参数如 --ar、--v）。

## 关键判断清单（判定流程/检查项）
- [ ] 主视觉是否把品牌资产放到最大、去掉干扰、多中心放置（醒目）？
- [ ] 画面核心信息是否3秒能说完、可口头复述（简单）？
- [ ] 是否与包装/终端/广告使用同一套品牌资产（重复）？
- [ ] 主视觉是否嫁接品类强相关文化母体并私有化？
- [ ] 文案是否一句话购买指令（口语化、陈述句/行动句、含产品名、不需解释）？
- [ ] 信息层级是否按卖点金字塔自上而下、主卖点唯一？
- [ ] 生图Prompt是否包含画面构成/色彩/风格关键词且中英双语？

## 边界与常见误区
- 误区：把KV当艺术海报，追求审美而牺牲记忆与说动。
- 误区：一张KV塞多个卖点，主信息不突出、抢戏。
- 误区：KV文案需要解释"内涵"——解释即失败。
- 误区：KV与包装/终端资产不一致，每次换画面等于丢资产。
- 边界：本卡为合成卡——KV是触点不是源头，画面依据来自承诺（产品＋话语）与记忆体（命名＋符号），不创造新方法论。
- 边界：KV生图Prompt为通用规范，可复制到任意生图平台使用；生图工具不可用时同样输出Prompt供用户自行使用。
