# dd 方法卡：企业社会责任（03_surface/csr）
> 依据：知识库 consulting/strategy/企业社会责任（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 企业是社会的器官，本身就是通过自己的产品服务于社会及社会需求——企业将自己的产品完成得越优秀，就是将社会责任完成得越优秀。
- 正确的社会责任一定是企业自身产品能完成的；完成之后，企业将成果展示于众，甚至鼓励更多人购买和使用自己的产品。
- 乱作无益："非其鬼而祭之，谄也。"——做本不该自己做的善事，只是博取好感的谄媚。
- CSR不独立于经营：社会责任、经营使命、企业战略三位一体（见公理）——CSR就是"把产品做好"本身。

## 方法要点

### 1. 乱作无益：为什么"做善事"式的CSR无效
- 许多企业将企业社会责任理解为做善事，目的无非是为了博取好感。
- 消费者并非傻子：当企业做着本不该自己做的善事时，顾客知道企业无非是为了博取好感，甚至认为企业会把做善事的成本计入销售中（如"每卖出1份即捐出X元"式操作）。

### 2. 最常见的三个错误方向
- 反对自己产品：如节能产品鼓励大众做节能公益（与自身产品立场冲突）。
- 貌似关联自己产品：如"含海洋生物精华"的产品发起"保护海洋"行动（牵强关联）。
- 打着品牌文化旗号讲故事：如女性用品品牌发起"女性宣言"（与产品无关的价值叙事）。
- 三个错误方向的共同点：CSR动作与自身产品脱节或对立——要么反对自己、要么貌似关联、要么无关讲故事。

### 3. 正确的社会责任
- 企业是社会的器官，本身就是通过自己的产品服务于社会及社会需求。
- 产品完成得越优秀＝社会责任完成得越优秀。
- 正确CSR＝企业自身产品能完成的；完成后将成果展示于众，甚至鼓励更多人购买和使用自己的产品。
- 判断标准：CSR动作应与产品、产能直接挂钩——做这件事的人就是"卖这个产品的人"，不另起炉灶。

### 4. 优秀CSR的3个特征
- 零负担：企业自身产能可达成，无需增加企业负担。
- 促增长：通过将过剩产能用于社会获取反馈，或加强投资产业消耗、降低企业采购成本——企业能力不会消耗反而能够壮大，从而更好服务社会。
- 可持续：由于有助于企业壮大，因此企业会持续投入，并在壮大之后加大投入。
- 三特征共同指向：优秀CSR是企业能力不被消耗反而壮大的动作——零负担是前提、促增长是机制、可持续是结果。

### 5. 2大共赢做法
- 企业溢出产能供给社会免费使用：如餐厅将当日剩余食材用于公益餐饮；服装企业捐赠淘汰库存；环保产品企业投资校企联合科技研发。
- 企业投资产业消耗再生：如造纸企业投资林场开发扩大；劳动密集型企业投资人力培育、创造就业。

### 6. CSR与品牌/战略的关系
- 正确CSR自带品牌效果：将成果展示于众、鼓励更多人购买和使用自己的产品，CSR与增长不冲突而是共赢。
- 与"乱作无益"相对：凡是需要做与本业无关善事的CSR，都是谄媚式操作，应剔除。
- CSR的可持续性即品牌的可持续性：有助于企业壮大的CSR，企业才会持续投入、并在壮大后加大投入。

## 关键判断清单（判定流程/检查项）
- [ ] 该CSR动作是否由企业自身产品/产能直接完成（而非另起炉灶做善事）？
- [ ] 是否零负担（企业自身产能可达成）？
- [ ] 是否促增长（过剩产能变社会反馈，或投资产业消耗降低采购成本）？
- [ ] 是否可持续（企业会持续投入，并在壮大后加大投入）？
- [ ] 是否落入三个错误方向（反对自己产品/貌似关联自己产品/打品牌文化旗号讲故事）？
- [ ] 是否避免"每卖出1份即捐出X元"式把善事成本计入销售的操作？
- [ ] 该CSR是否作为"把产品做好"的一部分被持续投入、随壮大加大投入（而非一次性善举）？
- [ ] 完成后是否将成果展示于众、鼓励更多人购买和使用自己的产品？

## 边界与常见误区
- 误区：把CSR等同于捐款捐物式的"做善事"——消费者看穿动机，并怀疑成本被计入销售。
- 误区：CSR与产品立场冲突或牵强关联——反对自己产品、貌似关联自己产品、打品牌文化旗号讲故事都是错误方向。
- 误区：CSR与生意脱节、不可持续——一次性的善举既不零负担也不促增长。
- 边界：CSR不独立于经营——它就是"把产品做好"本身；社会责任、经营使命、企业战略三位一体（见 principles.md 公理）。
- 边界：本卡不覆盖与本业无关的捐款捐物式公益形式的设计方法——此类内容不在知识库范围内，不编造方法论。
- 边界：CSR方案须从企业自身产品/产能出发设计；涉及行业数据与公益落地资源时，需用户提供或另行调研。
