# dd 方法卡：营销全案（03_surface/plan）
> 依据：知识库 consulting/growth/定力定型定投、低成本建品牌-雪球式增长、增长方式总论-4P是影响成交的变量；consulting/brand/品牌三进程-记忆惯性信仰；consulting/strategy/战略-创意即战略与经营原则（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 全案＝三层贯通的整合：Deep（使命与战略选战场）→ Middle（增长方式与4P协同）→ Surface（命名/符号/口号/包装/海报/CSR物料）。
- 全案总纲是"定力·定型·定投"：业务精炼、品牌精炼、套路精炼；资产第一天就定型；抓住有效打法持续复制。
- 全案的成功标准：战略首先在成本上成立——自身经营成本持续降低，竞争对手的进入成本持续垒高。

## 方法要点

### 1. 起点：企业本质与使命
- 企业是社会的器官：为解决什么社会问题而存在；社会问题＝商业机会。
- 三位一体：企业社会责任／经营使命／企业战略，使命决定战略；先有使命，后有战略。
- 使命3要素：对谁？做什么？凭什么？

### 2. 战略定位：选战场
- 战略的本质是选战场：只打拥有局部优势的战场；战略重点是舍弃。
- 战略就是选择做什么、不做什么；定位的核心意义在于明确不做什么。
- 先定义，后定位：把自己产品的名词解释（编进《现代汉语词典》的那句）整踏实，再谈定位。
- 创意即战略：大方向什么都不是，必须定具体创意；没有完成最后那惊险的创意一跳，一切都等于0；策略对了，成功就只是时间问题；创意对了，时间就不是问题。

### 3. 增长方式与4P协同
- 4P是影响成交的变量，不是分类；增长方式决定4P共同服务的方向（3P服务于1P）。
- 产品驱动型：产品利润＞顾客体验成本，4P设计成产品体验与产品优越性。
- 推广驱动型：产品利润＜顾客体验成本，4P设计成购买的必要性、即时性、冲动性。
- 渠道驱动型：顾客无法抹除信息差，4P设计成渠道的意愿与认知统一。
- 价格不是增长方式：价格是利润分配方式（分给后向研发/顾客/渠道销售者）。
- 营销＝制造前序体验：传达并促使顾客相信品牌承诺；营销设计不符合增长方式，整个营销失效，投得越多亏得越多。

### 4. 品牌承诺与记忆体
- 品牌＝承诺（产品＋话语）＋记忆体（命名＋符号）。
- 承诺端：核心承诺＝一句话购买理由；卖点金字塔6层从实到虚；超级话语＝说动不说清。
- 记忆体端：命名＝成本/召唤/投资；超级符号＝文化母体＋私有化改造；名字是君、图形是臣。

### 5. 资产储蓄与定力·定型·定投
- 资产定型：品牌资产最好在品牌开始销售的第一天就持续输出同一个资产，储蓄同一个品牌记忆；品牌升级＝丢掉原有的资产储蓄；越厉害的品牌越不愿意搞品牌升级。
- 资产储蓄规划：包装/店陈/传播统一使用核心资产（包装是心智储蓄罐：资产放最中心、放多处、可复述）。
- 营销定投：确定一两个有用的渠道持续投、扩大投；全渠道营销＝焦虑与投机；每增加一种营销套路往往就是一次冒险；警惕"新营销"。
- 降成本三原则：业务精炼（核心产品越少越好，越有机会提升到极高的产品水平）、品牌精炼（品牌内容越少记得越牢，不发展"品牌联想"）、套路精炼（有效模型持续扩大复制，团队越做越熟练、成本越做越低）。
- 战略定力：始终把资源控制在核心业务上，持续改善、厚积薄发；没有定力，就等于持续丢弃战略投入。

### 6. 品牌三进程的阶段性规划
- 记忆：营销动作＝存储品牌资产，成果＝顾客认识并记住品牌（"这是个牌子，不是不能买"）。
- 惯性：营销动作＝驯化顾客、反复创造购买场景，成果＝熟悉且感觉安全（"我懒得考虑别的牌子"）；设计顾客可加入的固定动作（固定时间/固定工具/固定的梗/固定仪式/固定事件）。
- 信仰：营销动作＝建立值得被捍卫的价值观，成果＝顾客粉品牌、主动捍卫（"我们都买他，我们是同类"）；大多由惯性自然生成，可以引导但很难制造。

### 7. 低成本起手：雪球式增长
- 雪球式增长：最初的体验者、购买者是小雪球，滚动时粘上新雪＝传播中粘到新的购买者；资金的作用是缩短进程。
- 第1步设计高效雪球：雪球够圆（记忆体超醒目，易传播、方便制造新的接收者）、够粘（承诺有打动力，易售出、方便制造新的购买者）。
- 第2步推动雪球的低成本3件套＝包装＋陈列＋人（顾客）：包装、陈列醒目呈现品牌资产；设计用户分享传播动作；人（顾客）＝自媒体＝私域池，建设用户俱乐部方便CRM、鼓励分享与复购。
- 第3步资金充分后投资品牌资产：低成本营销并不是正确手段，而是受限条件下的手段；经营拓展资金充分后仍应投入品牌资产建设，雪球越大滚得越快。

### 8. 全案整合检查（经营原则）
- 营销即研发：把产品整明白，然后直截了当说出去；成天研究怎么说，只有一个原因——自己的产品没整明白。
- 知名度第一：知名度是终极优势、消费者的第一反射；投资知名度包赚不赔。
- 竞争的本质是赢得顾客，不是打败对手；营销工作的重点是创造市场，而不是市场份额。
- 战略就是选择做什么、不做什么，留点事给别人解决。

### 9. 咨询工作路径与工序
- **核心流程顺序（成果物产生顺序）**：先确定增长驱动型 → 再设计对应 4P 模式 → 最后输出营销物料与计划。咨询成果物的产生有顺序，不可倒置。
- **工作路径五步**：意图与价值（使命愿景价值观）→ 战略（内外动因/创新战略条件）→ 增长方式 → 4P 行动与 4P 外立面 → 品牌资产（营销物料）。
- **两大阶段**：① 调研访谈观察学习、寻找战略要点；② 创意品牌资产、展开营销设计（根据增长方式，从品牌资产到营销核心工具的设计）。
- **三层交付清单**：
  - 战略设计：企业资源禀赋梳理 / 业务领域规划 / 产品结构规划 / 事业理论规划 / 战略条件明确 / 战略模型明确。
  - 品牌资产设计：品牌命名 / 产品体系命名 / 符号与图腾 / 口号与主张 / 包装店陈设计 / 广告模式设计 / 品牌画册 / VI 标准。
  - 品牌营销设计：营销扩张模式明确 / 明星产品包装 / 产品开发协助 / 营销日历规划 / 广告创意 / 营销事件创意 / 招商册页 / 终端营销策略规划 / 整套成果物。
- **成果物＝4P 的外立面**：品牌 VI、KV、包装设计、货架、门头招牌、广告海报、产品册页、菜单、电视广告、电商详情页、使用说明、销售话术、促销活动创意等。
- **输出物逻辑顺序**：企业战略/战略要点/调研报告/命名确定 → 视觉方案/品牌沟通语系 → 视觉延展/VI手册/品牌画册/营销规划。

## 关键判断清单（判定流程/检查项）
- [ ] 使命是否明确（对谁/做什么/凭什么）？与CSR、战略是否三位一体？
- [ ] 是否明确不做什么（舍弃清单）？是否只打拥有局部优势的战场？
- [ ] 增长方式是否判定清晰（产品/推广/渠道驱动）？4P是否3P服务1P、价格分配是否明确？
- [ ] 承诺与记忆体是否成型（一句话购买理由＋命名＋符号＋话语）？
- [ ] 品牌资产是否第一天定型、全触点统一（包装/店陈/传播）？
- [ ] 是否确定1-2个持续投放渠道（定投而非全渠道）？
- [ ] 是否规划记忆→惯性→信仰三阶段的阶段性动作？
- [ ] 低成本起手是否配置雪球三件套（包装/陈列/人）？
- [ ] 全案在成本上是否成立（自身成本持续降低、对手进入成本持续垒高）？

## 边界与常见误区
- 误区：全案＝一堆模块的堆砌——必须三层贯通、一个承诺贯穿到底。
- 误区：追求"品牌升级"与频繁改版——丢资产。
- 误区：全渠道营销、追逐新营销套路——焦虑与投机、造成浪费。
- 误区：只定大方向不定具体创意——创意即战略，没有创意策略等于零。
- 边界：全案不提供实时行业数据——数据需用户提供或另行调研；未覆盖内容明示，不编造。
