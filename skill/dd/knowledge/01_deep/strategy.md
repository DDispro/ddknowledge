# dd 方法卡：战略（01_deep/strategy.md）
> 依据：知识库 consulting/strategy/ 企业两大职能与战略定义、战略的本质-选战场、生意生存原理、企业三原理、产品结构-品类与路线图、战略-创意即战略与经营原则 6 个条目（已净化：无机构品牌、无案例、无品牌举例）。本卡是咨询回答的唯一知识来源。

## 核心定义
- **企业战略 = 企业计划用什么产品创造什么顾客**；产品是战略的唯一表达，产品组合 = 战略模型的具体化；创新是战略的唯一方式。
- **战略的本质是选战场**：只打拥有局部优势的战场；战略重点是舍弃；赢的方式是复制。
- **战略是涌现的、被发现的**：扩大自己已发展出来的最强业务线，而不是臆想一个新战略。

## 方法要点

### 1. 企业两大基本职能与开飞机模型
- 两大基本职能：**创新**（发想新产品、创造新市场）+ **营销**（卖出产品、创造新顾客）；两者相加基本构成企业战略。"基本职能"含义：永远别停止思考这两件事。
- 开飞机模型：燃料 = 资本与现金流；机身 = 企业运营（人员、生产、房租，全是成本，越轻盈飞得越轻松）；两翼 = 产品组合（战略唯一表达，设计越科学飞得越好）；发动机 = 营销与创新。
- 好的企业始终保持发动机高效运转：飞得越高阻力越小、惯性越足，所需燃料越少却仍能保持高速飞行。
- **企业不可以硬创新**：第二曲线最好在第一曲线上自然生长出来；新战略往往从原有业务范畴中派生。
- 新战略 = 新产品 + 新顾客 + 匹配的营销打法；母品牌在早期为子品牌提供信任背书，子品牌最终必须完全独立存活。

### 2. 选战场（战略的本质）
- 战场决定你面对的敌人、将获得的胜果、将采取的打法、需投入的资源；因为不可能拥有无限资源、不可能面对太多种类对手、不可能一次性打赢所有战场。
- 正确战场标准 = **拥有局部优势**：市场都卖高端 → 性价比有机会；市场高中低都有 → 针对特色人群有机会；特色挑花眼 → 回归基础款有机会；大家都便宜了 → 整合供应链有机会；大家都供应链了 → 抓渠道资源有机会；渠道已饱和 → 附加价值有机会。
- 完整战略三部分：①盘点（能力、优势、空间）；②确定（产品、顾客、资源）；③计划（从推出到营销到售出的完整销售套路，简单可复制）。
- 定战略三重点：**重点是舍弃**（为集中力量获得特定优势，不再满足其他需求）；**打法是简单**（有优势且满足需求就该轻松拿下客户，不轻松说明战略错了）；**赢的方式是复制**（舍弃其他打法集中复制，不可复制说明打法错了）。
- 战略是涌现过程：多数时候不需要思考创意，而需要观察和等待；任何时候的方针一样——扩大已经发展出来的、最强的、增长最快最高的、最有价值的业务线。

### 3. 生意生存原理
- 企业是社会的器官：本质任务 = 创造顾客；本质红利 = 完成社会职能的奖励（越稀缺、越被认可，奖励越多）；完成社会责任的方式 = 做好产品、完成产品承载的创新承诺。
- **利润不是目的，生存存续才是目的**：利润 = 持续生存的条件 + 创新的资本 + 评估经营管理的度量衡。
- 增长的停止是必然的，只有创新能制造新增长；成本的相对增长是必然的，只有把成本逐步转向创新区域才能对抗。
- 创业 = 企业从 0 到 1 的周期穿越；所有的穿越周期只能靠创新；资本是企业家穿越周期的资源。
- **只有企业有战略，不存在品牌战略或营销战略**——品牌是成果，营销是过程；成果和过程没有战略，只有策略或战术。
- 总成本领先 = 创新型要素（独有的技术、资源、组合、管理方式）+ 边际型要素（规模带来的资源虹吸或成本降低）。
- 成本是"经营、生意"无比底层的内涵性要素：生意 = 低成本地运作出较高利润；成本越低、利润越高，就是越好的生意。

### 4. 企业三原理
- 科斯原理 = 交易成本；德鲁克原理 = 社会职责；熊彼特原理 = 创新利润——三个角度构成理解企业价值的基本视角。
- 企业社会价值三层次：①让人提到你马上想到拳头产品（产品认同）；②扮演某领域"首席知识官"，成为公众、消费者乃至政府的习惯性咨询依赖（知识权威）；③代表人类某一方面追求的梦想化身（梦想象征）。
- 垄断与创新：每一个成功的企业实际上都是"垄断"企业，靠解决一个独一无二的问题获得垄断地位；**垄断是激励创新的动力**——没有垄断利润就没有企业家愿意创新；动力机制：垄断利润 → 企业家愿意创新 → 垄断地位巩固延续。
- 熊彼特五个创新：新产品或产品新特性；新生产方法；新市场；新原料或半成品来源；新组织（建立或打破垄断地位）。

### 5. 产品结构与品类路线图
- 产品结构 = 企业发展路线图：三要素 = 每支产品扮演的战略角色、承担的战略任务、推出的战略次序；决定成功的几率和营销投资的效率；所有的会战，都是为了最后的决战。
- 围棋模型（金角银边草肚皮）：金角占据制高点，银边拉出包围圈，目标指向草肚皮，天下归心成大局——产品推出次序按围棋布局思维设计；**战略的本质是位置**。
- 起手式很重要：起手式的差别与对未来价值版图企图心的差距，决定我们能走多远；思想决定认识，认识决定方向，方向决定方法，方法决定方式。
- **品类价值大于品种价值**：要建立品类价值并赢得解释权；抢占新类别、创造新类别，赢得新类别的解释权。
- 品类投资 = 跑马圈地，永远越圈越大；品种投资 = 登山，历经艰辛总有爬上山顶的时候。
- 建立竞争壁垒，提高竞争者的进入成本：从种一棵摇钱树，到建立整个果园。
- 三现两原：现场、现物、现实（使用现场、产品现物、消费者行为现实）+ 原理、原则（学习、理解客户的业务，然后重新想象、重新设计）。

### 6. 创意即战略与经营原则
- 大方向什么都不是，必须定具体创意；没有完成最后那惊险的创意一跳，一切都等于 0；**创意就是战略**；没有创意，策略等于零；没有手艺，创意等于零。
- 先定义，后定位：先把产品名编进词典（名词解释怎么写）整踏实，好多事都解决了。
- 营销即研发：把产品整明白，然后直截了当说出去；整明白了就一劳永逸地重复说、不断重复说。
- 知名度第一：知名度不是初级阶段而是**终极优势**、消费者的第一反射；不断投资知名度是包赚不赔的生意。
- 竞争的本质是赢得顾客，不是打败对手；胜在己，败亦在己。
- 市场份额是伪命题：那张饼是自己或其他人假设定义的，市场可以任意定义；营销工作的重点是**创造市场**，不是市场份额。
- 永远没有产品同质化这回事：认为行业"已进入同质化时代"，只是江郎才尽。
- 经营原则：调研不是客观的（任何"观"都是"主"在观）；国际化不是外国化；别让客户毁掉你的战略（真正的战略家会让一些客户不高兴，甚至让他们走开）；**多花钱少上人**（人是固定成本，钱是可变成本，尽量缩小组织规模）；战略就是选择做什么、不做什么。

### 7. 波士顿矩阵（产品组合管理）
- 四种产品角色：**明星产品**（增长产品，投资营销转化为现金牛）；**现金牛产品**（常规运营，为明星/问题产品提供资金）；**问题产品**（有潜力，需投资营销成为明星）；**瘦狗产品**（不投入，主动放弃）。
- 转化与投资方向：实线＝转化方向，虚线＝投资方向——投资从现金牛流向明星与问题产品，明星产品经投资营销转化为现金牛，问题产品可培育为明星。
- 战略含义：产品组合的每支产品都有明确的战略角色、任务与投资次序，与"产品结构＝企业发展路线图"呼应——钱从哪里来、投到哪里去、哪支产品承担增长、哪支产品负责供血，一目了然。

### 8. 增长战略三角（终极增长模型）
- 三角结构三边：
  - **品牌（最终成果）＝承诺＋记忆体**：品牌是增长战略的最终成果，由承诺（产品＋话语）与记忆体（命名＋符号）构成。
  - **企业（基本职能）＝战略＋创新＋营销**：创新是战略的唯一方式、产品是战略的唯一表达、营销是产品卖出的唯一依托——战略、产品、营销三事一体。
  - **增长（必然过程）＝产品穿透力＋价格穿透力＋4P行动与穿透力**：增长是必然发生的过程，落地为产品的穿透力、价格的穿透力，以及 4P 行动与穿透力。
- **三事一体**：战略、产品、营销三者一体、不可分割——没有战略的产品是盲目的，没有产品的战略是空的，没有营销的产品卖不出去。
- **永续增长三问**：我们的生意是什么（用什么产品和顾客）？我们生意的驱动方式是哪一种？我们最终留下的品牌资产是什么？

## 关键判断清单（判定流程/检查项）
- [ ] 能否一句话回答"用什么产品创造什么顾客"？
- [ ] 是否在打拥有局部优势的战场（先盘点能力/优势/空间）？
- [ ] 战略是否明确舍弃清单（不满足哪些需求、不做什么）？
- [ ] 打法是否简单到能轻松拿下客户（不轻松 = 战略错了）？
- [ ] 打法是否可复制（不可复制 = 打法错了）？
- [ ] 战略是观察等待中"发现"的，还是臆想的新战略？
- [ ] 第二曲线是否从第一曲线自然生长（而非硬创新）？
- [ ] 利润是否用于创新、是否为市场不景气留够利润、有无管理耗散？
- [ ] 产品结构是否按围棋次序设计（金角 → 银边 → 草肚皮）？
- [ ] 是否在建立品类价值并赢得新类别解释权？
- [ ] 成本上是否成立（自身经营成本持续降低、竞争者进入成本持续垒高）？
- [ ] 组织是否"多花钱少上人"（缩小固定成本）？

## 边界与常见误区
- 只有企业有战略，不存在"品牌战略/营销战略"：品牌是成果，营销是过程。
- 硬创新是错误：第二曲线应在第一曲线上自然生长出来。
- 别让客户毁掉你的战略：没有人能让所有人满意；战略家会让一些客户不高兴。
- 市场份额是伪命题：别被"份额"带节奏，重点是创造市场。
- 定了大方向不等于定了战略：没有具体创意的策略等于零。
- 调研不是客观的：相信客观 = 放弃自己的主观、相信别人的主观。
- "产品同质化"是借口：永远没有产品同质化这回事。
- 战略不是赢得所有市场：不可能赢下所有战场，只打有优势的市场。
