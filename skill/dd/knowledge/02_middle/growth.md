# dd 方法卡：增长方式（02_middle/growth）
> 依据：知识库 consulting/ 条目（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 增长方式 = 生意实现增长的客观驱动分型；4P 是影响成交的四个变量，也是区分增长方式的坐标。
- 营销 = 制造前序体验 = 传达并促使顾客相信品牌承诺；前序体验是购买决策的前提。
- 三种增长驱动：产品驱动型 / 推广驱动型 / 渠道驱动型；价格不是增长方式。

## 方法要点
### 1. 前序体验：购买决策的前提
- 研究商品怎么被卖出，本质是研究用户如何形成最终购买决策。
- 决策必然存在前提：用户通过自己的"前序体验"，认为自己应该或可以购买；潜客经历前序体验后成为顾客。
- 前序体验的本质：传达并促使顾客相信品牌的承诺，只是各个生意用的方式不同（有的靠亲身体验，有的靠广告与促销刺激）。
- 概念链条：营销 ↔ 制造增长 ↔ 制造前序体验；4P 恰好完整覆盖前序体验（即增长方式）的不同形态，可以按图索骥明确自己的增长方式。

### 2. 4P 是影响成交的变量，不是分类
- 在所有营销理论中，只有 4P 体系完整全面，且每个子集清晰、相互独立——如同描述一套住宅分为厅、卧室、厨房、卫生间、阳台五个部分，完整无遗漏、互不交错。
- 现实困境：4P 常被用来"解释"营销行动而从未被用来"操作"营销，沦为"商学院理论"；根源在于把 4P 当成分类方式，分类只能用于事后讨论案例。
- 定义决定应用：把 4P 定义为影响成交的变量，才会在每次需要工作时掏出这个工具。
- 营销设计一旦不符合增长方式，整个营销失效，投得越多亏得越多。

### 3. 三种驱动型增长：判定条件与营销核心
- 产品驱动型：商品利润 ＞ 让顾客体验品牌承诺的成本；营销核心 = 把 4P 设计成产品体验与产品优越性。
- 推广驱动型：商品利润 ＜ 让顾客体验品牌承诺的成本；营销核心 = 把 4P 设计成购买的必要性、即时性、冲动性。
- 渠道驱动型：高信息差品类，顾客无法抹除信息差、无法自主评估好坏，第一反应是"去哪里买/找谁买"；营销核心 = 把 4P 设计成渠道的意愿与认知。
- 判定是**互斥单选**：是哪一类就是哪一类，不存在"70%产品驱动＋30%渠道驱动"式的百分比混合；判定一旦明确，就决定了 4P 要整体塑造为服务哪一 P（3P 服务于 1P）。判定以两项硬条件为准：利润 vs 体验成本（区分产品/推广驱动）、顾客能否抹除信息差（区分渠道驱动）；经典行业分类速查见下。

### 4. 经典行业分类速查（常见咨询场景，直接对号）
> 这些行业是咨询中最常见的，可先按行业直接定位驱动型，再用硬条件复核。

- **产品驱动型**（产品利润＞顾客体验成本）：房产汽车、大宗交易物、奢侈品、线下服装品牌、耐用品牌、高单价数码电器、B2B 业务等。
- **推广驱动型**（产品利润＜顾客体验成本）：餐饮、包装食品、生鲜农副零售、日用快消品、OTC 医疗健康品、大部分电商品牌等。
- **渠道驱动型**（顾客无法抹除信息差）：① 评估难度高——部分厨电（如烟机灶具）、大型家居家具用品、理财保险等金融商品；② 可选太多且无统一认知标准——茶叶、茶具、小家电、礼品型商品等。

### 4.1 分型互斥与模型调度
- **互斥单判**：分型不是比例，是哪一类就是哪一类；不存在"70%产品驱动＋30%渠道驱动"的混合说法。判定清楚，就决定了营销 4P 要整体塑造为服务哪一 P。
- **判定后的调度**：明确驱动型后，应调度对应驱动型的 4P 模型卡提供具体咨询——
  - 产品驱动型 → 调度 `02_middle/product.md`（4P 各端参考 product/price/place/promotion 卡中的产品驱动模式）
  - 推广驱动型 → 调度 `02_middle/promotion.md`
  - 渠道驱动型 → 调度 `02_middle/place.md`

### 4.2 4P动力谱罗盘速查（各驱动型的完整4P行动模式）
> 罗盘用途：判定驱动型后，按对应表格整体塑造 4P（3P 服务 1P）。三张表格分别给出产品/推广/渠道三种驱动型的完整 4P 行动模式。

**产品驱动型——4P 表达产品优越性**

| 4P | 行动模式 |
|----|----------|
| Product | 更精美的包装、优于市场均值的功能、更美好的产品设计、更好材质、独特服务设计、独特附加体验 |
| Place | 体验型门店空间、服务型销售人员、鼓励试用的体验流程、高价值感陈列设计 |
| Promotion | 高价值圈层互动、用户俱乐部、同价提供更高级商品、鼓励二手交易迭代促销、优先获得或优先服务、更优雅或昂贵的广告模式 |
| Price | 利润分配给研发供应链等后向、相对高价、坚挺价格线、以阶层设计价格、稀缺溢价（如限量版） |

**推广驱动型——4P 表达购买的必要性/即时性/冲动性**

| 4P | 行动模式 |
|----|----------|
| Product | 包装强化产品目的性、极其方便识别、色彩冲击、大容量及简化包材、提供附加实用利益、辅助购买信息清晰 |
| Place | 抢夺优势排面、依托购买指令梳理陈列、组织清库存促销、大规模分销 |
| Promotion | 限时让利、高频迭代上新吸睛、巨量广告、爆款IP阶段引流 |
| Price | 利润分配给顾客等前向、低利润模式、对标同款、0利润甚至负利润抢夺用户基本盘 |

**渠道驱动型——4P 统一渠道意愿与认知**

| 4P | 行动模式 |
|----|----------|
| Product | 强化细分特征、突出选择标准、高端与量销区隔、突出行业地位、引入背书认证资源 |
| Place | 培养专家、促进渠道生动化私有化、培训式顾客体验活动、分级管理与优秀经验复制 |
| Promotion | 紧贴渠道的广告投放、官方补贴大促、行业公关 |
| Price | 利润分配给渠道支配、相对统一性、官方高价支撑为零售提供优势价、赠品替代折扣 |

**价格是第 4 驱动力**：价格的内涵是利益分配，永远附着于其他 3P、不单独发挥作用——附着产品＝利益分配给研发与供应链、附着推广＝利益分配给顾客、附着渠道＝利益分配给销售。

### 5. 3P 服务于 1P：4P 协同服务增长重心
- 增长方式定义了 4P 共同服务的方向；其他 3P 都要扮演和传达服务重心那 1P。
- 产品驱动型 → 3P 服务产品优越性；推广驱动型 → 3P 服务购买冲动；渠道驱动型 → 3P 服务渠道意愿。
- 产品驱动型尤甚：即使顾客没体验过产品，光看渠道门脸、销售人员服务姿态、价格标签、推广活动与广告，也能脑补出产品本身的优越性。
- 反向即错配：某个 P 抢戏（如产品驱动型生意让低价促销当主角、推广驱动型生意只做高大上体验而忽视即时冲动），协同即被破坏。
- 各驱动型的 4P 行动模式详见方法卡 02_middle/product.md / price.md / place.md / promotion.md。

### 6. 增长方式诊断三问
- 你的产品利润能支持顾客直接体验吗？→ 产品驱动型。
- 你的产品需要靠推广刺激即时购买吗？→ 推广驱动型。
- 你的顾客需要渠道引导才能做购买决策吗？→ 渠道驱动型。

### 7. 价格不是增长方式
- 不存在"价格驱动型"增长方式：价格驱动力对所有增长方式都有效，只是用法不同。
- 价格不单独发生作用：本质是商品利润的分配方式，必须依托另外 3P 才发挥作用（详见方法卡 02_middle/price.md）。

## 关键判断清单（判定流程/检查项）
- [ ] 单客利润 vs 让顾客体验品牌承诺的成本：利润 ＞ 成本 → 产品驱动；利润 ＜ 成本 → 推广驱动。
- [ ] 行业是否存在顾客无法抹除的信息差（评估难度高 / 可选太多无统一标准）？→ 是 → 渠道驱动。
- [ ] 所属行业是否在经典分类速查中？若是，直接对号后再用硬条件复核。
- [ ] **分型是否互斥单选**？是否明确"是哪一类就是哪一类"，而非"70%产品＋30%渠道"式混合？
- [ ] **判定后是否已调度对应驱动型的 4P 模型卡**（产品→product、推广→promotion、渠道→place）？
- [ ] 4P 是否全部协同服务于同一增长重心（3P 服务 1P），而非各自为政？
- [ ] 是否存在错配动作：推广驱动生意搞沉浸式体验而忽视即时冲动刺激；产品驱动生意乱打低价促销摧毁产品优越感；渠道型生意忽视对渠道人员的认知赋能？
- [ ] 价格设计是否与该增长方式的利润分配方向一致，而非独立拍板？
- [ ] 判定后是否按'增长方式→4P模式→营销物料/计划'的顺序输出成果物？

## 边界与常见误区
- 误区：把 4P 当成分类表格，只用于事后解释营销行动，而不是用于操作营销。
- 误区：以为存在"价格驱动型"增长方式——价格不是增长方式。
- 误区：增长方式错配仍加大投入——营销设计不符合增长方式时，投得越多亏得越多。
- 边界：每种驱动型的营销只适用于对应生意；一旦用于其他驱动型生意，营销将失效甚至产生反效果。
- 边界：产品驱动型不等于不做推广、不碰渠道、不用促销价格，而是所有动作都要与产品驱动相匹配。
