# dd 方法卡：产品（02_middle/product）
> 依据：知识库 consulting/ 条目（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 产品的本质 = 购买理由：消费者遇到的问题就是一个需求、一个购买理由；根据购买理由开发产品。
- 产品开发 = 购买理由设计：先策划购买理由，再把产品做出来；营销的工作是对产品进行再开发。
- 产品即命名：找到购买理由就找到产品名称，产品名称是一个超级词语，用超级词语下达购买指令。
- 产品开发就是设计一套选择逻辑（设计选择题）。

## 方法要点
### 1. 产品是购买理由
- 购买动力不是需求而是理由：购买理由在心理上是一种打动机制。
- 购买理由基于品类价值，而又高于品类价值。
- 开发产品就是从消费需求出发开发购买理由：把购买理由写下来，交给技术人员去实现。
- 产品开发创意服务的定位："购买理由设计师"。

### 2. 产品开发六步骤
- 第一步 品牌寄生：找到母体，一口咬上去就能获得原力。母体 = 社会生活反复出现的仪式、传统文化中生命力长受众面广的事物；产品寄生到母体，成为该场景中价值感最强的角色。
- 第二步 寻找购买理由：只有有明确购买理由的产品，才有畅销的可能。
- 第三步 产品命名：产品即命名，先有词语后有产品；命名的本质是放大购买理由（把购买理由直接写进产品名，如"30分钟长效"式把功效写进名字）。
- 第四步 产品翻新：调整产品以满足购买理由，而不是调整购买理由去迁就产品。
- 第五步 主题化开发：形成主题，复制到其他产品上，共用模具，降低开发成本与失败风险。
- 第六步 引发情感共鸣：带给消费者发现感和价值感。

### 3. 多翻新，少创新
- 产品开发就是洞见消费欲望，是撩拨需求和满足想象；本质是让顾客"心想事成"。
- 手段上多"翻新"、少"创新"，降低新品风险；推陈出新，在强大的老需求基础上不断翻新新需求。

### 4. 产品即命名（命名承担说服与召唤）
- 将购买理由命名产品，将大大降低营销成本、提升传播效率，并且降低消费者的选择成本。
- 最好产品名就是购买理由：命名本身承担说服与召唤功能。
- 广告创意就是产品再开发。

### 5. 设计一套选择逻辑（设计选择题）
- 产品开发就是设计选择题：设计选择的逻辑和范围，让我们的产品自动成为选择的结果，优化购买和使用体验。
- 应用方式：按人群、年龄、使用场景等维度细分"对号入座"，让顾客直接选中本品；或开发场景化主题产品系列。

### 6. 卖点金字塔（6 层，自下而上由弱到强）
- 第 6 层 降低消费门槛或成本：如"19.9元吃到饱"式具体价格/门槛表述。
- 第 5 层 技术特征强化说服力：如"充电5分钟通话2小时"式具体可验证的技术表述、"晒足180天"式具体化。
- 第 4 层 比竞品更能满足功能。
- 第 3 层 第三方认可资质背书：如"指定/专用"式权威背书表述。
- 第 2 层 热销实证：如"一年卖出X杯""100万用户选择"式从众证据。
- 第 1 层 领导者实证特权：行业第一的实证地位，说服力最强。
- 卖点原则：要精炼（外立面空间有限，只能呈现最主要的部分；把所有空间填充同一个卖点效果才好，次级卖点只做补充说明、不抢戏）；要具体（卖点非形容词，每个人读起来得到同样的信息）。
- 顾客对卖点的感受就是在建立购买认知、确认购买和消费的安全度：认知路径 = 不确定 → 少损失 → 从众 → 证据证实范围扩大 → 安全感提升 → 满足功能 → 极确定；安全的底线选择是"少损失"，最安全的选择是"大品牌"。

### 7. 产品驱动型增长的产品端：产品优越性三种表现
- 功能优越：完美满足期待。
- 价值优越：高附加价值感。
- 身份优越：服务的优越性（专属贵宾服务等）。
- 产品端动作：更精美的包装、优于市场均值的功能、更好的设计材质、独特的服务设计与附加体验。

## 关键判断清单（判定流程/检查项）
- [ ] 该产品的购买理由是什么？能否一句话写下来并交给技术实现？
- [ ] 是否找到了可寄生的文化母体（反复出现的仪式/传统文化）？
- [ ] 产品名是否直接放大/写出购买理由（先有词语后有产品）？
- [ ] 是否优先调整产品去满足购买理由，而不是改理由迁就产品？
- [ ] 是否以"翻新"为主控制新品风险、以主题化复制降低开发成本？
- [ ] 卖点是否精炼（只呈现最主要的一个）且具体（非形容词）？
- [ ] 卖点是否优先使用金字塔上层（领导者实证/热销/背书）？
- [ ] 若属产品驱动型生意，产品端是否支撑功能/价值/身份优越？

## 边界与常见误区
- 误区：把产品开发当成纯技术实现，跳过购买理由的策划。
- 误区：卖点堆砌形容词（如"飞一般的感觉"式），每个人读到不同信息。
- 误区：卖点贪多，把次级卖点铺满外立面，稀释主卖点效果。
- 误区：总想"创新"全新品类，忽视在强大老需求上翻新的低风险路径。
- 边界：产品驱动型的打法只适用于产品驱动型生意（详见方法卡 02_middle/growth.md）。
