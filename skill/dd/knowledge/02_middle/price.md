# dd 方法卡：定价（02_middle/price）
> 依据：知识库 consulting/ 条目（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 价格是 4P 中最独特的要素：不存在"价格驱动型"增长方式；价格驱动力对所有增长方式都有效，只是用法不同。
- 价格不单独发生作用：本质是商品利润的分配方式，必须依托另外 3P 才发挥作用。
- 定价 = 利润分配设计：设计价格前先确认生意的增长方式，价格策略应与该增长方式的利润分配方向一致。

## 方法要点
### 1. 价格为什么独特
- 4P 的增长方式坐标只有三种（产品、推广、渠道），价格不在其列；但任何增长方式都离不开价格设计。
- 价格是"利润分配"视角而非单纯的"成本加成"视角：同样的定价行为，在不同驱动型生意中服务于完全不同的目的。

### 2. 产品驱动型：利润分配给后向链路
- 利润分配给研发、供应链、服务链等影响商品优越性的整个生意的后向链路。
- 价值通过商品优越性、服务优越性、体验优越性呈现。
- 定价表现：相对高价、坚挺的价格曲线、以阶层设计价格、稀缺溢价（如限量版价格）。

### 3. 推广驱动型：利润分配给顾客
- 利润分配给顾客，以"降价、超值体验"等方式诱导顾客直接购买。
- 定价表现：低利润模式，0 利润甚至负利润抢夺份额；捆绑打包、拼团销售。

### 4. 渠道驱动型：利润分配给销售者
- 利润分配给销售者，由销售者掌握；销售者凭借自己的专业说服力，调整他与顾客之间的利润分配。
- 分配逻辑：销售者越专业、说服力越强，利润分配给自己越多；说服力越弱，利润分配给顾客越多。
- 定价表现：相对统一性，官方高价为零售提供优势价，以赠品替代折扣作为经销商的利润空间。

### 5. 价格端与三种驱动型的协同（3P 服务 1P）
- 产品驱动型：价格是产品优越性的组成部分——顾客光看价格标签就能脑补产品优越性。
- 推广驱动型：价格是刺激即时购买的工具——让顾客感到"现在买划算"，提示易得性。
- 渠道驱动型：价格是武装销售者的工具——留足渠道空间，让销售者卖得有动力、有说服空间。
- 同样的让利行为：产品驱动型生意中会摧毁优越感，推广驱动型生意中却是核心武器——定价必须跟随增长方式。

### 6. 应用含义
- 设计价格前先确认生意的增长方式，价格策略应与该增长方式的利润分配方向一致，而不是独立拍板。
- 销售者说服力是渠道驱动型生意价格分配的杠杆：企业可以通过培训、背书增强销售者专业度，从而改变分配结果。
- 定价审查顺序：先定增长方式 → 再定利润分配方向 → 最后定具体价格带与折扣/赠品机制。
- 渠道驱动型中，赠品替代折扣是常用结构：既留足经销商利润空间，又维持零售端价格形象。

### 7. 三种驱动型的价格模式速查
| 增长方式 | 利润分配方向 | 定价表现 | 价格动作 |
|---------|-------------|---------|---------|
| 产品驱动型 | 后向链路（研发/供应链/服务链） | 相对高价、坚挺溢价曲线、阶层定价、稀缺溢价 | 维持高价，不轻易打折 |
| 推广驱动型 | 顾客 | 低利/0 利/负利、捆绑打包、拼团 | 让利诱导即时购买 |
| 渠道驱动型 | 销售者 | 统一价、官方高价、赠品替代折扣 | 留足渠道空间、武装销售者 |

## 关键判断清单（判定流程/检查项）
- [ ] 该生意的增长方式是什么（产品/推广/渠道驱动）？
- [ ] 本次定价的利润要分配给谁：后向研发链路 / 顾客 / 渠道销售者？
- [ ] 产品驱动型：是否维持相对高价与坚挺溢价曲线，避免低价摧毁优越感？
- [ ] 推广驱动型：是否敢用低利/0 利/负利抢份额，配合捆绑打包与拼团？
- [ ] 渠道驱动型：是否统一价、官方高价为零售留优势价、以赠品代替折扣留渠道空间？
- [ ] 价格动作是否与另外 3P 协同（3P 服务 1P），而非独立拍板？

## 边界与常见误区
- 误区：认为存在"价格驱动型"增长方式——降价不是增长方式。
- 误区：以"成本加成"视角孤立定价，无视增长方式的利润分配方向。
- 误区：产品驱动型生意乱打低价促销，摧毁产品优越感与溢价曲线。
- 误区：渠道驱动型生意直接给终端降价打折，压缩销售者的利润空间与说服动力。
- 边界：价格必须依托另外 3P 发挥作用，不能单独产生驱动效果。
