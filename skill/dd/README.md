# dd 品牌营销方法论 SKILL（MarketingPro）

基于第一性原理的品牌营销咨询工具，覆盖品牌诊断、咨询问答、物料生成、战略全案四项核心能力。

## 安装与使用

- 将本目录（`dd/`）作为 SKILL 加载到支持 SKILL.md 规范的 AI 工具中；
- 调用 `/dd [你的问题或业务描述]` 即可获得基于标准知识库的专业回答；
- 也可直接 `/dd-brand`、`/dd-growth`、`/dd-naming` 等 15 个子指令定向调用模块（详见 SKILL.md 命令体系）。

## 目录结构

```
dd/
├── SKILL.md              主入口：命令体系、运行协议、知识保障规则
├── README.md             本文件
├── knowledge/            标准知识库（方法卡，所有回答的唯一知识来源）
│   ├── main_map.md       全景逻辑总图
│   ├── principles.md     核心公理集（跨模块通用）
│   ├── 01_deep/          品牌 / 战略 / 定位
│   ├── 02_middle/        增长方式 / 产品 / 定价 / 渠道 / 推广
│   └── 03_surface/       命名 / 符号 / 口号 / 包装 / KV海报 / CSR / 全案
├── dd-brand/ ... dd-plan/   15 个子模块（SKILL.md：场景SOP + 输出格式）
└── templates/            输出模板（诊断报告 / 战略全案）
```

## 知识保障说明

- 所有回答均基于 `knowledge/` 方法卡生产，并在输出中标注依据；
- 知识库未覆盖的问题会明确告知，不会用其他来源的方法论冒充；
- 知识内容已净化：不包含任何咨询机构品牌名、不编造案例。
