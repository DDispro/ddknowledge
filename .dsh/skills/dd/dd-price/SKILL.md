## 核心方法论速览（浓缩自知识卡）
1. 不存在"价格驱动型"增长方式：价格驱动力对所有增长方式都有效，只是用法不同。
2. 价格不单独发生作用：本质是商品利润的分配方式，必须依托另外 3P 才发挥作用。
3. 设计价格前先确认生意的增长方式，价格策略应与该增长方式的利润分配方向一致，而不是独立拍板。
4. 产品驱动型：利润分配给后向链路（研发/供应链/服务链）——相对高价、坚挺溢价曲线、阶层定价、稀缺溢价。
5. 推广驱动型：利润分配给顾客——低利/0 利/负利抢份额、捆绑打包、拼团。
6. 渠道驱动型：利润分配给销售者——统一价、官方高价为零售留优势价、以赠品代替折扣留渠道空间。
7. 价格是"利润分配"视角而非"成本加成"视角：同样的定价行为在不同驱动型生意中目的完全不同。

## 触发场景
- 用户询问怎么定价、怎么调价、促销怎么做。
- 用户需要渠道价格体系设计（进价/零售价/促销价/经销商利润空间）。
- 用户的价格动作与增长方式疑似错配（如高端品乱打折、渠道型生意直接给终端降价）。
- 用户需要理解价格与利润、增长方式的关系。

## 场景SOP
### 场景A：诊断（现有定价审查）
1. 确认增长方式：该生意是产品/推广/渠道驱动？
2. 对照分配方向：当前定价的利润实际分配给了谁（后向链路/顾客/销售者）？
3. 检核错配：产品驱动却低价促销？渠道驱动却直接给终端降价？推广驱动却不舍得让利？
4. 输出诊断结论与纠偏方向。

### 场景B：咨询（定价策略问答）
1. 锁定增长方式与利润分配方向。
2. 给出对应定价模式：
   - 产品驱动 → 高价 + 坚挺溢价曲线 + 阶层/稀缺定价。
   - 推广驱动 → 低利让利 + 捆绑拼团 + 限时优惠。
   - 渠道驱动 → 统一价 + 官方高价 + 赠品替代折扣。
3. 说明价格如何与其他 3P 协同（3P 服务 1P）。

### 场景C：成果物生成（定价方案）
1. 输出价格策略说明书：增长方式 → 分配方向 → 定价原则 → 具体价格带/价格结构。
2. 输出渠道价格体系（如适用）：官方价/零售价/促销价/经销商利润空间。
3. 输出执行提示：哪些价格动作绝不可做（与该驱动型错配的动作）。
