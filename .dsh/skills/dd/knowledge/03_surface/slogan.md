# dd 方法卡：超级话语/口号（03_surface/slogan）
> 依据：知识库 consulting/growth/超级话语-口号与广告语设计、卖点金字塔（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 超级话语＝用一句话发动消费者大规模购买；需要低成本、容易记、乐于传。
- 广告的基本原理是刺激反射：不是说服消费者，而是说动消费者；广告语是设计一句话让他说给别人听（播传）。
- 口号是品牌承诺端"话语"的核心表达，直接承载购买理由。

## 方法要点

### 1. 口语化：传播是一种口语现象
- 先有口语，后有书面语；语言是一种口语现象，口语是一切交流的基础，书面语从属于口语。
- 书面语只属于眼睛，口语属于眼睛、耳朵和嘴巴；书面语的传播效率不及口语的万分之一。
- 互联网时代，是重返口语时代。
- 超级语感：一目了然、过目不忘、脱口而出、不胫而走——最重要是一目了然；对超级句式，人们只需阅读关键词就能获得完整的意义和情绪。

### 2. 只用陈述句和行动句
- 陈述句：陈述一个事实（如"晒足XX天"式工艺陈述、"一座城市多个项目"式地产陈述）。
- 行动句：下达购买指令（如"送长辈，XX酒"式）。
- 一句话如果什么也没定义，也没对人提行动要求，就不要用。
- 霍布斯：语言的首要用处在于名词的正确定义，首要滥用在于没有定义。

### 3. 说动不说清
- 说清是相对的，说动是绝对的：你以为你说清了，其实他没听清；他终于听清了，他听清的和你说的不一样。
- 说动是绝对的：动了就动了，没动就没动；高手追求说动而不是说清。
- 广告不要"说什么、怎么说"，要"说什么，直接说"。

### 4. 俗语不设防，押韵就相信
- 押韵创造一种事实感：顺口溜的音韵和节奏能突破受众的心理防线，创造一种愉悦的接受。

### 5. 品牌口号四问
- 顾客认不认、员工用不用、对手恨不恨、顾客传不传。

### 6. 不要解释
- 如果一句口号需要另一句话去解释它的"内涵"，把那口号扔掉，直接用后面那句。
- 如果一个标志需要写一个标志释义来解释，把那标志扔掉——它连自己都解释不了，还能解释什么。

### 7. "某品，不只是……"是广告禁用句式
- 使用这种句式有两种情况：一是不能准确定义自己（说不清自己是啥）；二是不甘心只说一样（想跟人说一大堆，又不知从何说起）。
- 两种情况都是错误的，应列为广告禁用句式。

### 8. 先定义，后定位
- 说到产品，人们会马上想到定位，这就跑偏了：任何问题先解决基本面、解决原点——你如何定义你的产品。
- 定义，就是把你的产品名编进《现代汉语词典》，后面那句名词解释怎么写；把这整踏实了，很多事都解决了。

### 9. 卖点原则：精炼＋具体
- 要精炼：外立面空间有限，只能呈现最主要的部分；把所有空间填充同一个卖点效果才好，次级卖点只做补充说明，不能抢戏。
- 要具体：卖点非形容词，每个人读起来得到同样的信息（"XX般的感觉"式表述，每个人的感觉不一样）。

### 10. 卖点金字塔（6层，说服力由强到弱）
1. 领导者实证特权
2. 热销实证（如"年销X杯"式销量陈述）
3. 第三方认可资质背书（如"某权威场景专用"式）
4. 比竞品更能满足功能
5. 技术特征强化说服力（如"充电X分钟通话X小时""晒足XX天"式）
6. 降低消费门槛或成本（如"X元吃到饱"式）
- 顾客对卖点的感受，就是在建立购买认知、确认购买和消费的安全度。
- 购买认知路径：不确定 → 少损失 → 从众 → 证据证实范围扩大 → 安全感提升 → 满足功能 → 极确定；安全的底线选择是"少损失"，最安全的选择是"大品牌"。

## 关键判断清单（判定流程/检查项）
- [ ] 口号是否口语化（朗读一遍是否像人话）？
- [ ] 是否陈述句/行动句（定义了事实或下达了购买指令）？
- [ ] 是否说动而不只是说清（刺激反射测试：听者会不会动）？
- [ ] 口号四问：顾客认不认？员工用不用？对手恨不恨？顾客传不传？
- [ ] 是否利用押韵/音韵节奏（俗语不设防，押韵就相信）？
- [ ] 是否还需要另一句话解释（需要就扔掉，用解释的那句话）？
- [ ] 是否误用"不只是"句式？
- [ ] 是否包含产品名？
- [ ] 卖点是否精炼＋具体（非形容词）？主卖点所处金字塔层级是否明确？

## 边界与常见误区
- 误区：追求"说清"产品全部信息——说清是相对的，说动是绝对的。
- 误区：形容词堆砌，每人理解不同——卖点必须具体、非形容词。
- 误区：多卖点并列，外立面被塞满，主卖点反而不突出。
- 误区：为"内涵"而隐晦，需要额外解释——解释即失败，直接说。
- 边界：口号不能脱离产品定义与承诺——先定义、后定位，先有购买理由，再有口号。
