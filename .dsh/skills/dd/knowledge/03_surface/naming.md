# dd 方法卡：命名（03_surface/naming）
> 依据：知识库 consulting/growth/命名论-命名就是成本召唤投资（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 命名就是成本！命名就是召唤！命名就是投资。
- 产品即命名：先有词语，后有产品——产品诞生的起点是名字。
- 命名是品牌记忆体（命名＋符号）的第一要素，是降低营销成本的起点。

## 方法要点

### 1. 命名的三性：成本、召唤、投资
- 成本：用大众熟悉的词语，让记忆成本、传达成本、理解成本都很低。
- 召唤：是词语的能动性——名字能把产品蕴含的卖点价值召唤出来。
- 投资：名字一旦确定，就是一项长期投资，随销售持续储蓄。

### 2. 命名第一原则：低成本
- 名字要传达成本低、传播成本低、理解成本低、使用成本低、营销成本低。
- 名字不是用来玩的，是用来用的：配送员、门店、顾客等不同角色都要用这个名字，使用成本要低。

### 3. 命名的本质：召唤性、指令性
- 命名要传递价值、传递购买理由、召唤顾客。
- 如果名字本身能传达价值、召唤顾客，就能降低传播成本，降低消费者的选择成本。

### 4. 命名必须是听觉词语
- 因为传播是口语现象、听觉行为：不仅要一看就明白，关键要一听就明白。
- 听觉词语便于口语传播，是名字能被"传起来"的前提。

### 5. 检验好名字的3个标准
- ①低成本：传达、传播、理解、使用、营销的各项成本都低。
- ②召唤性、指令性：能传递价值和购买理由、召唤顾客。
- ③听觉词语：一听就明白，便于口语传播。

### 6. 命名为了区分异类，不区分同类
- 名字不是为了区分同类，而是为了区分异类；首先要的是跟同类在一个类里。
- 用消费者听得懂的方式命名：同一产品，通俗、有画面感的命名远胜生僻音译或洋名——好的命名降低记忆与传播成本。
- 世界就是认识，认识就是分类；分类就是贴标签，贴标签就是词语和符号。
- 命名原则：内涵没有任何价值，外延才有价值。

### 7. 广告语里一定要有产品名
- 广告语的创意同样是为了降低成本，广告语里面一定要有产品名。
- 产品名直接进入口号，口号同时是购买指令（如"XX一开，好运自然来""送长辈，XX酒"式）。

### 8. 名字与图形的主从关系
- 在品牌识别中，名字是"君"，图形是"臣"；名字是红花，图形是绿叶。
- 标志设计的创意价值，在于降低识别和记忆品牌名字的成本。

## 关键判断清单（判定流程/检查项）
- [ ] 名字是否用大众熟悉的词语（无生僻字、无难懂音译）？
- [ ] 名字是否一听就明白（听觉词语测试：旁人听一遍即懂、能复述）？
- [ ] 名字本身是否传递价值/购买理由、能召唤顾客（指令性）？
- [ ] 名字是否与同类处于同一个类（不是为区分同类而生僻化）？
- [ ] 广告语/口号中是否包含产品名？
- [ ] 标志是否服务于降低识别和记忆名字的成本（名字为君、图形为臣）？

## 边界与常见误区
- 误区：追求"高大上""独特"而用生僻音译或洋名——增加记忆与传播成本，违背低成本第一原则。
- 误区：把名字当创意作品来玩，忽视不同人群在实际使用场景中的使用成本。
- 误区：为区分同类而过度差异化——正确目标是区分异类、与同类同框。
- 边界：名字召唤的是产品已蕴含的卖点价值，不能凭空创造卖点——命名不替代产品与承诺本身。
- 边界：命名属于品牌记忆体（命名＋符号）的设计，与话语（口号）配合使用——广告语必须含产品名，口号同时是购买指令（见 slogan 卡）。
