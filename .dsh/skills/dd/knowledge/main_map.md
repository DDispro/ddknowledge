## 起点：生意的第一性原理

```
社会未满足需求 ＋ 企业独特能力 ＋ 企业使命 ══(三位一体)══> 企业存在成立
```

- 企业是社会的器官：本质任务是为社会解决问题，帮社会把资源从低效率处搬到高效率处。
- 每一个社会问题都是一个商业机会；巨大的社会问题就是巨大的商业机会。
- 企业社会责任、经营使命、企业战略三位一体，使命决定战略；先有使命，后有战略。
- 企业三原理：科斯（交易成本）、德鲁克（社会职责）、熊彼特（创新利润）。
- 利润不是目的，是持续生存的条件、创新的资本、经营管理的度量衡。

## 第一站：动态经营飞行器（企业两大基本职能）

```
【机身】运营成本（人员、生产、房租——越轻盈越好，对抗管理耗散）
【两翼】产品组合（产品是战略的唯一表达，产品组合=战略模型的具体化）
【发动机】营销与创新（德鲁克唯二职能：营销=卖出产品创造新顾客；创新=新市场穿越周期）
【燃料】资本与现金流（保障基本运营与两大职能执行）
```

- 企业不可以硬创新：第二曲线最好在第一曲线上自然生长出来。
- 战略是涌现的、被发现的：扩大已发展出来的最强业务线，而不是臆想新战略。
- 五种创新方式：新产品/新生产方法/新市场/新原料来源/新组织方式。
- 总成本领先 = 创新型要素（独有技术、资源、组合、管理方式）+ 边际型要素（规模带来的资源虹吸或成本降低）。
- 战略的本质是选战场：只打拥有局部优势的战场；战略重点是舍弃；赢的方式是复制。
- 产品结构=企业发展路线图（围棋模型：金角银边草肚皮）；品类价值＞品种价值；抢占新类别赢得解释权。

## 第二站：中层 4P 动力谱（三种增长驱动）

> 核心原则：**4P是影响成交的四个变量，不是分类**。增长方式定义了4P共同服务的方向。

| | 产品驱动型 | 推广驱动型 | 渠道驱动型 |
|---|---|---|---|
| **判定条件** | 产品利润 ＞ 顾客体验成本 | 产品利润 ＜ 顾客体验成本 | 顾客无法抹除信息差 |
| **4P服务重心** | 产品优越性 | 购买的必要性/即时性/冲动性 | 渠道的意愿与认知统一 |
| **Product** | 卓越功能/质感包材/高附加值 | 目的性强/醒目/大容量 | 行业标准/背书认证 |
| **Place** | 体验型门店/服务型人员 | 优势排面/大规模分销 | 专家培养/生动化/培训 |
| **Promotion** | 圈层俱乐部/会员/优雅广告 | 限时让利/巨量广告/爆款 | 紧贴渠道投放/行业公关 |
| **Price** | 相对高价/坚挺溢价曲线 | 低利抢份额/捆绑拼团 | 统一价/留足渠道空间 |

- **价格不是增长方式**：价格是利润分配方式，依托另外3P发挥作用（分给研发后向链路 / 分给顾客 / 分给渠道销售者）。
- 3P服务于1P：其他3P都要扮演和传达服务重心那1P。
- 营销=制造前序体验=传达并促使顾客相信品牌承诺；增长方式错配=营销失效。

## 第三站：品牌作用力内核（承诺 ＋ 记忆体）

```
品牌 = 承诺（说服内核：产品+话语） ＋ 记忆体（提示外壳：命名+符号）
     = 企业给自己设计的方便顾客奖惩的标签
```

- 品牌唯一目的 = 复购（0成本复购）；终极效果 = 取消销售。
- 品牌是结果不是方法：首先必须卖得多，才能成为品牌。
- 品牌资产 = 只属于你、用户凭此识别的要素（名称、标识、图腾、口号、提示音）；
  也是能产生效益的消费者认知（具体、可描述、需长期积累）。
- 超级符号 = 嫁接文化原型（占人类文化的便宜）：人人看得懂、人人照着做；
  符号就是资产，持续重复积累；不开发符号，只寻找、继承、发扬旧符号。
- 品牌三进程：记忆（醒目/简单/重复）→ 惯性（固定动作）→ 信仰（共同捍卫价值观）。
- 品牌战略铁三角：话语体系 ＋ 超级符号 ＋ 产品结构。
- 品牌三原理：资产观（资产是能带来效益的消费者认知）、失灵论、成本论（降低社会监督/顾客选择/企业营销三成本）。
- 品牌展现成本越高（广告越大），惩罚可能性越高，作用力越强。

## 终点：雪球滚动与终极商业闭环

```
【前序体验/被营销体验】──(模拟体验、打动承诺)──> 【初次购买】
        ▲                                          │
        │                                          ▼
【品牌资产持续储蓄】<──(0成本复购/口碑推荐)── 【消费体验】
        │
        ▼
【终极效果：取消销售】→ 品牌资产取代销售员 → 获取存续利润 → 投入下一次创新（穿越周期）
```

- 低成本建品牌：雪球式增长——体验者/购买者是雪球核，传播粘上新的购买者；雪球要圆（记忆体醒目）、要粘（承诺有打动力）；三件套=包装+陈列+人（顾客=自媒体=私域）。
- 定力·定型·定投：业务精炼、品牌精炼、套路精炼；资产第一天就定型；抓住有效打法持续复制。
- 营销定投优于全渠道：确定一两个有用的渠道持续投、扩大投；全渠道营销=焦虑与投机。
