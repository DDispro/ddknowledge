# dd 方法卡：推广（02_middle/promotion）
> 依据：知识库 consulting/ 条目（已净化）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 推广驱动型生意：产品利润不足以支持顾客先体验，只能靠推广手段直接刺激、诱导顾客先掏钱购买。
- 营销核心：把 4P 设计成购买的必要性、即时性、冲动性。
- 推广的成果是心智占有：让顾客记住，为下一次购买场景做准备；记忆度要求最高。
- 有效跨界 = 推广驱动型生意 ×（强度 + 爆炸 + 社交）；低成本建品牌靠雪球式增长。

## 方法要点
### 1. 推广驱动型增长的特征与判定
- 典型生意：餐饮、包装食品、生鲜农副零售、日用快消品、OTC 医疗健康品、大部分电商品牌等。
- 判定：商品利润 ＜ 让顾客体验品牌承诺的成本——顾客只能自己掏钱购买之后才真正体验到承诺，因此需要用推广手段直接刺激、诱导用户先购买成交。
- 判定示例（数字逻辑）：某餐饮单品利润 40 元、让顾客试吃成本 60 元，则营销越多亏越多；改为发 30 元优惠券诱导购买，营销就不亏。

### 2. 营销核心：必要性、即时性、冲动性
- 总原则：以建立即时性刺激、降低购买心理门槛、提示易得为中心展开营销设计。
- 强化购买必要性："家中常备"式话术；以用途直接命名产品（把好处写进名字）。
- 建立购买冲动：应用场景美化、多巴胺营销。
- 提示商品易得性：限时特价、第二件半价式设计；先让顾客产生购买是第一位的。

### 3. 记忆度要求最高（心智抢占）
- 顾客没有立刻购买怎么办？那就让顾客牢牢记住，为下一次购买场景做准备。
- 推广驱动型生意对品牌沟通的"记忆度"要求最高：即使现在不买，未来有需求时也要第一时间回忆到这个品牌。
- 做法：巨量媒介投放 + 极其简化的信息信号——功能式口号（把功效写进口号）、数字配方式口号（"1:1:1"式数字配方）、成分式口号（"0糖0脂0卡"式成分列举）。
- 呼应公理：知名度是终极优势、消费者的第一反射，投资知名度包赚不赔；竞争的本质是赢得顾客，不是打败对手。

### 4. 4P 行动模式（3P 服务购买冲动）
- Product：包装强化产品目的性、极易识别、色彩冲击、大容量装及简化包材、提供附加实用利益、辅助购买信息清晰（直接标价、直接说明成分）。
- Place：抢夺优势排面、依托购买指令梳理陈列、组织清库存促销、大规模分销。
- Promotion：限时让利、高频迭代上新吸睛、巨量广告、爆款 IP 阶段引流。
- Price：低利润模式，0 利润甚至负利润抢夺份额，捆绑打包、拼团销售（详见方法卡 02_middle/price.md）。

### 5. 有效跨界营销
- 先想清楚"谁成就谁"：是双方品牌原有的实力成就了跨界，而不是跨界成就了品牌；这是每个想搞跨界的老板需要审慎思考的问题。
- 品牌不需要年轻化：品牌就是承诺 + 记忆体；不承诺年轻的品牌不需要年轻化，需要的是活跃度，所有品牌都需要活跃度。一个品牌当年用吸睛形象做广告时没人觉得它年轻，多年后同样的形象持续发声，反而让人觉得"活跃"——老品牌还经常有效发声，就是年轻。
- 有效跨界公式：有效跨界 = 推广驱动型生意 ×（强度 + 爆炸 + 社交）：
  - 强度保障：最强者 + 最强者。
  - 爆款可能性：双方均实现巨大反差。
  - 社交可能性：可晒、可分享。
- 只有推广驱动型生意跨界营销才有效（餐饮、包装食品、生鲜农副零售、日用快消品、OTC 医疗健康品、大部分电商品牌等）。
- 强者的奢侈品：成功跨界的真正成果，是双方联手在声量上肃清竞争对手；只有最强者 + 最强者才有这种合作可能和营销效果。因为有效营销需要击穿刺激屏障，有效的跨界是"强者的奢侈品"；无效的跨界看起来也营销了，却只能带来资源和精力上的浪费。

### 6. 低成本建品牌：雪球式增长
- 品牌在顾客心中壮大的 6 条路径：看到广告、看到或参与推广活动、看到陈列、看到包装、听见有人推荐（聊天分享）、看见有人推荐（晒图分享）。
- 成本差异：广告、推广活动 = 高成本制造购买者/体验者；陈列、包装 = 低成本制造购买者/体验者；听见推荐、看见推荐 = 低成本制造接收者，分别考验销售力与传播力。
- 机制：接收者越多 → 购买者或体验者越多 → 复购者和传播者也越多 → 进而传播给更多接收者。
- 雪球式增长：最初的体验者、购买者是小雪球；小雪球滚动时粘上新雪，相当于传播过程中粘到新的购买者；资金投入的作用是缩短进程、加大推雪球的速度——滚得越快雪球越大，雪球越大粘上新雪越快。
- 低成本营销三步：
  - 第 1 步 设计高效雪球：设计有强大购买理由、易被复述的品牌资产——雪球要圆（记忆体超醒目，易传播、方便制造新的接收者）、要粘（承诺有打动力，易售出、方便制造新的购买者）。
  - 第 2 步 推动雪球的低成本三件套 = 包装 + 陈列 + 人（顾客）：包装、陈列醒目呈现品牌资产；设计用户分享传播动作；人（顾客）= 自媒体 = 私域池，建设用户俱乐部方便 CRM，鼓励分享与复购。
  - 第 3 步 资金充分后要投资品牌资产：尽快开始花钱——低成本营销并不是正确手段，而是受限条件下的手段；经营拓展资金充分后仍应投入品牌资产建设，因为雪球越大滚得越快、长得越快。
- 方法论内涵：品牌与增长方式必须一体设计（整体决定局部）。

## 关键判断清单（判定流程/检查项）
- [ ] 判定：单件利润是否小于让顾客体验品牌承诺的成本？（是 → 推广驱动型）
- [ ] 4P 是否协同服务于必要性、即时性、冲动性（3P 服务 1P）？
- [ ] 品牌沟通的记忆度是否足够：信号是否极其简化、能被第一时间回忆？
- [ ] 跨界前先问"谁成就谁"；是否属于推广驱动型生意；是否满足最强者 + 最强者、巨大反差、可晒可分享？
- [ ] 低成本起手：雪球是否够圆（记忆体醒目）、够粘（承诺有打动力）？三件套（包装+陈列+人）是否到位？
- [ ] 资金充分后是否仍在投资品牌资产（而不是把低成本当成正确手段）？

## 边界与常见误区
- 误区：品牌需要"年轻化"——品牌需要的是活跃度。
- 误区：把跨界当作万能增长手段——非推广驱动型生意跨界无效；非最强者的跨界浪费资源与精力。
- 误区：把低成本营销当成正确手段——它是受限条件下的手段，资金充分后应投资品牌资产。
- 误区：只做曝光不做记忆——推广驱动型生意的记忆度要求最高。
- 边界：推广驱动型营销只适用于推广驱动型生意；用于其他驱动型生意将失效甚至产生反效果。
