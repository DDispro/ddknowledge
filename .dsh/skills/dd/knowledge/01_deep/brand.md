# dd 方法卡：品牌（01_deep/brand.md）
> 依据：知识库 consulting/brand/ 全部 8 个条目（已净化：无机构品牌、无案例、无品牌举例）。本卡是咨询回答的唯一知识来源。

## 核心定义
- **品牌 = 承诺 + 记忆体** = 企业给自己设计的方便顾客奖惩的标签。承诺端（说服内核）= 产品 + 话语；记忆体端（提示外壳）= 命名 + 符号。
- **品牌唯一效应 = 复购**（0 成本复购）；**终极效果 = 取消销售**（品牌资产取代销售员，什么也不干顾客仍反复购买、到处说你好）。
- **品牌是营销的成果，不是方法**：首先必须卖得多，才能成为品牌；做品牌 = 设计销售方式 + 设计记忆方式。

## 方法要点

### 1. 承诺与记忆体（品牌的全部内容）
- 认知并传播一个事物必含三要素：具体物、描述、指代方式；指代方式统帅一切，一个词就能指认。
- 品牌三要素：产品（具体物）+ 符号（指代方式）+ 话语（描述）。
- 产品 + 话语 = 品牌承诺（说服顾客，让其相信并接受承诺而购买）；产品 + 话语 + 符号 = 品牌记忆（引导、提示购买）。
- 品牌全部内容就两条：①产品 + 话语构建有打动力的承诺；②把产品与话语导入符号形成记忆体。营销就是把以上内容植入消费者大脑，此外不需要任何别的内容。

### 2. 奖惩机制（品牌为何有效）
- 顾客奖励 = 购买 + 推荐；顾客惩罚 = 拒买 + 劝退；只有品牌才有"砸招牌"一说。
- 品牌是消费者风险机制与对企业惩罚机制的集合：品牌 = 企业创造重复博弈，给消费者惩罚自己的机会；机制有效则品牌有效，机制无效则品牌失灵（失灵论）。
- 改过机制：品牌犯错后积极认错改正，反而可能赢得更深信任——印证"我不会逃过惩罚、不会背叛承诺"，下一回购买依然可以不假思索。
- **品牌展现成本越高，作用力越强**：投放量级本身是"正经大品牌"的安全感体验；广告是帮顾客想象产品的"替代式体验"，看了广告才第一次买，本质已是第二次体验（复购）。

### 3. 识别与记忆（品牌第一要务）
- 品牌第一要务 = 识别：识别不到你无法复购；识别不深刻记不住你没得复购；识别不简单不易传播没得复购。"你有品牌"= "江湖上有你一号"。
- 构建记忆三原则：**醒目**（资产能放多大放多大、干扰信息能去掉就去掉、放置位置能多中心就多中心）、**简单**（简单才易复述：3 秒说完、15 秒播 5 遍；简单省制作费）、**重复**（所有地方部署同一套资产；除非有了新资产，否则不做新广告）。
- 品牌三进程：**记忆**（"这是个牌子，不是不能买"）→ **惯性**（"我懒得考虑别的牌子"）→ **信仰**（"我们都买他，我们是同类"）。
- 惯性靠驯化：设计顾客可加入的固定动作（固定时间、固定工具、固定的梗、固定仪式、固定事件），动作多、时间长，惯性思维就形成。
- 信仰可以引导但很难制造，大多由惯性自然生成：内涵 = 共同人 + 共同价值观或生活方式；外延 = 共同组织、共同行为、共同话语。

### 4. 品牌资产（资产观）
- 资产两个判定标准：①只属于你；②用户凭此就能识别你。基本包括：名称、标识、图腾、口号、提示音等。
- 品牌资产 = 能产生效益的消费者认知：具体、可描述、需长期积累；用途 = 支持产品销售，让人们更容易信任和购买。
- 资产 3 形态（产品/符号/话语）+ 3 类附着载体；载体（如包装）应充分担当承载资产的作用；名称对另外两类资产具有完全统治力。
- 资产必须文本化：只有能被说出口、被复述的资产，才可能被传播、被记住。
- 明确非资产：品牌明星不是资产；品牌联想不是资产；没有被记住的特征都不是资产。
- 资产审计：一切动作以"是否形成、保护、增值资产"为标准；能形成资产 = 有效动作，不能 = 废动作，减少废动作是运营管理的核心。
- 投资储钱罐观：投下去的每分钱都要有储存——用结构投资降低运营风险，持续积累型投资优于"一战定成败"；创意审核要提到战略高度。
- 资产储蓄观：广告 = 模拟体验（前序体验 = 向客户展示承诺）；任何体验都应有留存资产，无留存资产的体验 = 无效体验 = 重新投入。

### 5. 超级符号（记忆体构建法）
- 超级符号 = 人人看得懂、人人照着做的符号（不只被认识，还会被听从）；三大威力：轻易改变品牌偏好、短时间发动大规模购买、让新品牌一夜之间成为亿万消费者的老朋友。
- 本质 = 嫁接文化原型：人们只记得已记得的、只认识已认识的；占领一个文化原型 = 占领该文化代表的所有财富（占人类文化的便宜）。
- **不开发符号，只寻找、继承、发扬旧符号**；汉字是中国品牌必备符号；没有符号的东西不卖，要卖永远也是卖符号。
- 符号就是资产：营销内容会过时、产品会更新换代，只有符号体系是永恒的；超级符号是起点（积累资产）也是终点（超级销售力）。
- 品牌角色 = 超级IP：品牌自己创造的代言人（他就是品牌本身），可长期重复投资积累，没有生老病死、与时俱进；品牌角色要有文化原型，没有原型很难生长。
- 集体潜意识沟通：要销售的东西若没扎根或至少捆绑于集体潜意识，几乎一定会失败。

### 6. 品牌三原理与成本论
- 三原理分别回答：资产观（品牌靠什么积累）、失灵论（品牌为何有效）、成本论（品牌为何存在）。
- 成本论：品牌的本质是降低三个成本——社会监督成本、顾客选择成本、企业营销成本；三者相辅相成（出了事大家马上抓你→消费者更放心选择你→企业营销成本低）。
- 消费者进入那个场景时不假思索选择你 = 选择你成本最低；让消费者本能购买 = 把成本降到最低。
- 本质论四词：**本质、常识、本能、成本**；抓住本质则"问题即答案"；离开常识、抓不住本质 = 浪费时间、损失金钱、迷失方向、丢掉机会。

### 7. 品牌战略铁三角
- 铁三角 = 话语体系 + 超级符号 + 产品结构；一个伟大的品牌就是一个伟大的超级符号系统。
- 话语体系：以超级话语为核心（一句话发动大规模购买），低成本、容易记、乐于传，口语化（传播是一种口语现象）。
- 超级符号：人人看得懂，可轻易改变偏好、短时间发动大规模购买。
- 产品结构 = 企业发展路线图：安排每支产品的战略角色、战略任务、战略次序，决定成功几率和营销投资效率；所有的会战都是为了最后的决战。
- 成本是战略成立的前提：该战略下自身经营成本持续降低（此消），竞争对手进入成本持续垒高（彼长），才能扩大优势、永续经营。

## 关键判断清单（判定流程/检查项）
- [ ] 能否一句话说清"我的承诺是什么、记忆体是什么"（产品+话语=承诺；命名+符号=记忆体）？
- [ ] 承诺是否足以让顾客敢买（安全感）？话语是否口语化、说动顾客？
- [ ] 记忆体是否醒目、简单、可复述（3 秒说完、15 秒播 5 遍）？
- [ ] 是否把品牌当方法（追求好看/故事/审美）而非当结果（先卖得多）？
- [ ] 是否存在进程错配（记忆阶段就追求信仰/品牌文化，废话连篇、脱离销售）？
- [ ] 每个创意、设计、活动是否经得起"形成、保护、增值资产"三问？
- [ ] 资产是否满足"只属于你 + 用户凭此识别"？是否文本化、可复述？
- [ ] 符号是否嫁接文化原型（人人看得懂、照着做），而非凭空创造新符号？
- [ ] 投放量级是否足以塑造"正经大品牌"的安全感体验？
- [ ] 是否在所有地方重复部署同一套资产（而非不断做新广告、搞资产升级）？
- [ ] 品牌犯错后是否践行"认错改正"以恢复信任？

## 边界与常见误区
- 品牌是结果不是方法：追求漂亮设计、美好故事、审美，既非充分条件也非必要条件，是叶公好龙的花架子。
- 没有形成品牌资产的推广 = 企业在花钱"复购"用户（无效营销 = 掏钱买顾客赚差价）。
- 心智是成果不是方法：不要以"树立细分市场第一心智"为动作目标（详见定位卡）。
- 别被差异化带节奏：顾客复购不是因为差异化，而是因为承诺是他想要的、喜欢的且完成得好。
- 品牌明星、品牌联想不是品牌资产；没被记住的特征都不是品牌资产。
- 天量广告投入不是"有钱烧"，而是"初体验塑造"；展现成本越高作用力越强。
- 载体失职：顾客买完、体验完，却忘了甚至不知道你是什么品牌 = 零留存、最差包装。
- 品牌工作对象是所有人，不只是目标消费者：人更多时候是传播者而非购买者。
