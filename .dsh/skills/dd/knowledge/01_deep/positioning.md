# dd 方法卡：定位（01_deep/positioning.md）
> 依据：知识库 consulting/strategy/ 定位的真义、使命的现实意义、企业本质-社会问题与三位一体 3 个条目（已净化：无机构品牌、无案例、无品牌举例）。本卡是咨询回答的唯一知识来源。

## 核心定义
- 定位分两种：**心智定位**（品牌识别）与**战略定位**（业务、经营、使命）；真正起作用的定位是战略定位。
- **定位的本质是一个自梳理**：从思想统一到行为统一；内部获得经营管理的降本增效，外部获得品牌认知的降本增效。
- **定位的最核心意义不是明确要做什么，而是明确不做什么**：只有不做某些要素，才能降本增效。

## 方法要点

### 1. 两种定位与心智定位误区
- 心智定位（品牌识别）对应"树立细分市场顾客第一心智"的主流理解；战略定位（业务、经营、使命）才是有效定位。
- 心智定位的误区：主流理解"树立细分市场顾客第一心智"，看起来好像没错，但实际上根本没用。
- 原因：品牌是营销的成果，不是定好位品牌就成立了；**心智是成果，不是达成目的的方法**。
- 一个品牌成为其品类的第一心智是成果，而不是"专注该品类的定位"帮助它成为第一。

### 2. 定位的本质：自梳理
- 从思想统一到行为统一。
- 内部获得经营与管理的降本增效；外部获得品牌认知的降本增效。
- 要回答四个问题：做什么的？什么特点？什么主张？怎么个做法？

### 3. 定位的目的：降低内外交易成本（三层次定位）
- 使命定位（社会需求 | 内部共识）：让内外部明确知道你是干什么的；推动企业文化（内）、品牌文化（外）。
- 经营定位（生产 + 营销独特套路）：让内部知道我们打算怎么做生意；特定套路构成成本优势。
- 业务定位（产品与产品组合）：内部形成产品共识，外部知道如何消费你；能力堆叠（内）、认知堆叠（外）。
- 通过明确战略定位实现产品与业务的固化，统一内外部知识信息及流程，减少新增项、干扰项，降低管理成本、教育学习成本、认知统一成本，使企业能力便于迭代生长——易于管理、易于竞争、易于改善。

### 4. 定位最核心意义：明确不做什么
- 不是明确要做什么，而是明确不做什么；只有不做某些要素，才能降本增效。
- 三层次各自的"不做"：使命定位——不提倡什么文化；经营定位——不做哪些生产与营销；业务定位——不售卖哪些产品。

### 5. 使命的现实意义
- 许多使命没用，两大原因：①老板当初只是看到机会想赚钱，没意识到使命；②把使命当企业文化去"教化"员工，而人都不愿意被教化，必然失效。
- **使命是利润来源**：企业能赚钱，是因为完成了社会自己完成不了的工作，社会将利润奖励给企业；社会越需求、越只有我们能完成，利润就越大；使命越大、越真实、越被需要，利润越足；没利润 = 需求不真实，或满足该需求的企业太多、社会不缺我们这一家。
- **使命是产品开发的发想点**：企业通过产品解决社会问题，使命就是产品开发发想点——一个使命可派生一系列产品。
- **使命是顾客生命周期**：使命不止是某一次用户需求的满足，而是顾客在整个生命周期中所有场景的同类型需求的满足；如果一次就能满足用户整个生命周期的需求，大概率是使命太小，生意难以持久壮大。
- 使命核心 3 要素：对谁？做什么？凭什么？——没有具体回答这三个问题，就等于没有使命。

### 6. 企业本质与三位一体模型
- 企业是社会的器官，是一种社会分工机制；企业的本质是为社会解决问题；**每一个社会问题都是一个商业机会，巨大的社会问题就是巨大的商业机会**。
- 创业的出发点应是解决问题，而不是想着开公司：先想清楚解决什么问题，再考虑创立企业。
- 企业战略不是企业自己的战略，而是企业为解决某一社会问题而为社会制定的战略；企业制造的产品和服务 = 该社会问题有效的、全面的、可持续的解决方案；战略思考的起点是"选择承担哪一项社会责任"，而不是"我做什么生意"。
- 三位一体模型（四要素）：社会问题 → 企业社会责任 → 经营使命 → 企业战略；逻辑链条：选择、承担解决某一社会问题的责任，并将之作为经营使命；**使命决定战略，先有使命，后有战略**。
- 企业战略等式：社会问题 = 商业机会 = 企业社会责任 = 经营使命 = 企业战略 = 业务组合和产品结构 = 社会问题解决方案。
- 社会责任不是企业的义务，而是企业的业务，而且是核心业务。
- 公关就是社会责任，是**战略产品**，要用产品开发的思维来做公关：用用户的思维做公关——"不是买我的东西，但是我的用户"。

## 关键判断清单（判定流程/检查项）
- [ ] 是否区分了心智定位与战略定位？（心智是成果不是方法，不可当动作目标）
- [ ] 定位是否回答了四问：做什么的/什么特点/什么主张/怎么个做法？
- [ ] 三层次定位（使命/经营/业务）是否齐备且内部共识一致？
- [ ] 是否明确列出"不做什么"清单（不提倡什么文化/不做哪些生产营销/不售卖哪些产品）？
- [ ] 使命是否包含 3 要素（对谁/做什么/凭什么）？
- [ ] 使命是否指向利润来源（社会问题的稀缺性：社会越需求、越只有我能完成）？
- [ ] 使命是否覆盖顾客全生命周期场景（而非单次需求满足）？
- [ ] 是否按"先找社会问题 → 确立社会责任与经营使命 → 再定战略"的次序操作？
- [ ] 是否把社会责任当核心业务（而非义务）来经营，包括公关？

## 边界与常见误区
- 心智定位误区："树立第一心智"是成果不是方法，看似正确实则无用。
- 有使命不等于使命有效：为赋使命而设的使命、用来教化员工的使命，都必然失效。
- 使命太小：一次就能满足顾客整个生命周期需求 = 使命太小，生意难以持久壮大。
- 定位不是一句定位语/口号：定位是自梳理与"不做什么"的决策过程。
- 战略定位要敢于舍弃：真正的定位会放弃部分市场，让一些客户不高兴。
- 定位以降低内外交易成本为检验：若未降低管理/教育/认知成本，定位未完成。
