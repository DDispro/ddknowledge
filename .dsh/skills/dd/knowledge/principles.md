# dd 核心公理集（跨模块通用）

> 所有模块共用的第一性原理公理。依据：知识库 consulting/ 条目（已净化：无机构品牌、无案例、无品牌举例）。
> 调用顺序：子模块方法卡不足时，回到本公理集；再不足时参考 main_map.md 全景总图。

## 一、品牌公理

1. **品牌 = 承诺 + 记忆体** = 企业给自己设计的方便顾客奖惩的标签。
   - 承诺端（说服内核）：产品 + 话语；记忆体端（提示外壳）：命名 + 符号。
2. **品牌唯一目的 = 复购**；终极效果 = **取消销售**（0成本复购，品牌资产取代销售员）。
3. **品牌是结果，不是方法**：首先必须卖得多，才能成为品牌；做品牌 = 设计销售方式 + 设计记忆方式。
4. **品牌发挥作用靠顾客奖惩**：奖励=购买+推荐；惩罚=拒买+劝退；认错改正可恢复信任。
5. **品牌第一要务是识别**：识别不到/不深刻/不简单，都无复购。
6. **品牌展现成本越高，作用力越强**：投放量级=给顾客"正经大品牌"的安全感体验。
7. **品牌工作的对象是所有人，不只是目标消费者**：人更多时候是传播者而非购买者，传播流量意义大于购买意义。

## 二、营销公理

1. **营销 = 制造前序体验** = 传达并促使顾客相信品牌承诺；前序体验是购买决策的前提。
2. **4P是影响成交的四个变量，不是分类**：产品、价格、渠道、推广各自独立又完整全面。
3. **增长方式决定4P方向**：产品驱动（3P服务产品优越性）/ 推广驱动（3P服务购买冲动）/ 渠道驱动（3P服务渠道意愿）。
4. **价格不是增长方式**：价格是利润分配方式（分给后向研发 / 分给顾客 / 分给渠道销售者）。
5. **营销的终极成果是品牌**；没有形成品牌资产的推广 = 企业在花钱复购用户。
6. **营销与销售对立**（德鲁克）：营销的成果是拥有品牌，品牌越强越不需要销售。

## 三、战略与经营公理

1. **企业是社会的器官**：本质=为社会解决问题；社会问题=商业机会；使命+能力+需求三位一体。
2. **先有使命，后有战略**；使命=打算帮社会解决什么问题从而赚来利润；使命核心3要素=对谁/做什么/凭什么。
3. **产品是战略的唯一表达**；战略=用什么产品创造什么顾客；战略是涌现的、被发现的。
4. **战略的本质是选战场**：只打拥有局部优势的战场；重点是舍弃；赢的方式是复制。
5. **增长停止是必然的，只有创新能制造新增长**；五种创新（新产品/新方法/新市场/新原料/新组织）。
6. **成本是生意无比底层的内涵**：总成本领先=创新型要素+边际型要素；利润不是目的是生存条件。
7. **垄断是激励创新的动力**：没有垄断利润就没有企业家愿意创新。
8. **生意差=社会提醒你该创新了**：企业是社会的器官，社会不需要这个器官就会淘汰它。

## 四、符号与话语公理

1. **超级符号 = 文化母体 + 私有化改造**：人人看得懂、人人照着做；不开发符号只寻找、继承、发扬旧符号。
2. **符号就是资产**：营销内容会过时、产品会更新，只有符号体系是永恒的；持续重复积累。
3. **命名就是成本、召唤、投资**：产品即命名；命名必须是听觉词语；用听得懂的方式命名（区分异类不区分同类）。
4. **超级话语 = 用一句话发动大规模购买**：口语化；陈述句/行动句；说动不说清；品牌口号四问（顾客认不认/员工用不用/对手恨不恨/顾客传不传）。
5. **先定义，后定位**：把自己产品的名词解释整踏实，再谈定位。
6. **卖点要精炼、要具体（非形容词）**；卖点金字塔6层从实证到门槛。

## 五、经营心法（观点公理）

1. **定力·定型·定投**：业务精炼、品牌精炼、套路精炼；资产第一天就定型（越厉害的品牌越不愿意搞品牌升级）；抓住有效打法持续复制。
2. **营销定投优于全渠道**：确定一两个有用的渠道持续投、扩大投；全渠道营销=焦虑与投机。
3. **竞争的本质是赢得顾客，不是打败对手**。
4. **至诚无息**：不博弈——只定最小目标（货真价实），目标以下忽视、以上视为赚到。
5. **警惕整合营销**：大道至简，简单化才少犯错、低成本；不妄图通过复杂操作获得极限胜利。
6. **知名度第一**：知名度是终极优势、消费者的第一反射，投资知名度包赚不赔。
7. **问题即答案**：抓住本质，答案就在问题背面。
8. **战略就是选择做什么、不做什么**：留点事给别人解决。
